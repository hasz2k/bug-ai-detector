## 🇬🇧 English

### Overview
**Bug AI Detector & Reporter** is a lightweight, single-page web dashboard designed for automated QA testing, AI-driven visual anomaly detection, and real-time telemetry analytics for game engines (such as Unreal Engine 5) and applications.

### 🌐 Live Demo
Experience the live application hosted via GitHub Pages:  
🔗 **[https://hasz2k.github.io/bug-ai-detector/](https://hasz2k.github.io/bug-ai-detector/)**

### ✨ Key Features
- **🤖 Autonomous AI Agents Dispatcher**: Manage dynamic test suites using Explorer, Spec-Driven, and Chaos/Stress testing agents.
- **📊 Real-Time Telemetry & Performance Tracking**: Monitor hardware anomalies, memory spikes (RAM/VRAM), and framerate drops (FPS).
- **🌐 Zero-Latency i18n Language Toggle**: Instant switching between English and Polish powered by an optimized DOM `MutationObserver`.
- **🎯 Visual Bounding Box Proof**: Interactive overlay displaying bounding boxes detected by vision AI models.
- **⚡ Zero-Dependency SPA Architecture**: Entire application runs from a single optimized `index.html` file without requiring node packages, build steps, or external servers.

## 🇵🇱 Polski

### Opis projektu
**Bug AI Detector & Reporter** to lekka aplikacja typu SPA (Single Page Application), zaprojektowana do automatyzacji testów QA, wykrywania błędów wizualnych przez modele wizyjne AI oraz analizy telemetrii w czasie rzeczywistym dla silników gier (np. Unreal Engine 5) i aplikacji mobilnych/webowych.

### 🌐 Live Demo
Zobacz wersję demonstracyjną udostępnioną na GitHub Pages:  
🔗 **[https://hasz2k.github.io/bug-ai-detector/](https://hasz2k.github.io/bug-ai-detector/)**

### ✨ Główne funkcje
- **🤖 Dyspozytor Autonomicznych Agentów AI**: Zarządzaj flotą agentów (*Explorer*, *Spec-Driven*, *Stress/Chaos Engine*) w ramach powtarzalnych sesji testowych.
- **📊 Telemetria i Analiza Wydajności**: Monitoruj spójność pamięci VRAM/RAM, rejestruj nagłe spadki klatek (FPS) oraz anomalie sprzętowe.
- **🌐 Dynamiczne Przełączanie Języków (PL/EN)**: Bezpośrednia zmiana języka interfejsu w czasie rzeczywistym bazująca na mechanizmie `MutationObserver`.
- **🎯 Wizualne Dowody Detekcji Błędów**: Prezentacja obszarów błędów (bounding boxes) zintegrowana z logami i instrukcją odtworzenia kroku.
- **⚡ Architektura Single-File SPA**: Pełna funkcjonalność w pojedynczym pliku `index.html`, bez konieczności budowania czy instalowania bibliotek przez `npm`.
